Автономний статичний застосунок для підготовки до сертифікаційного іспиту Anthropic **Claude Certified Architect — Foundations (CCA-F)**. Жодної збірки, жодного сервера, жодних залежностей для встановлення — завантажте папку та відкрийте `index.html` у браузері.

## Відкриття файлу

Двічі клацніть по [index.html](index.html) або обслуговуйте його через будь-який статичний файловий сервер. Прогрес зберігається локально в браузері (`localStorage`), окремо для кожного пристрою/браузера. Тримайте `style.css` і `content.js` поруч з `index.html` — застосунку потрібні обидва файли; якщо відкрити лише `index.html`, замість завантаження з'явиться помилка. Також додайте папку `translations/`, якщо потрібна мова, відмінна від англійської — без неї застосунок непомітно перемкнеться на англійську.

## Що всередині

Сторінка являє собою оболонку з вкладками, що об'єднує чотири інструменти. На широких екранах (від 900px) вона фіксується в макеті з фіксованою висотою та закріпленою верхньою панеллю навігації, тож кожен інструмент прокручується незалежно; нижче цієї ширини сторінка повертається до єдиної безперервно прокручуваної сторінки.

| Вкладка | Призначення |
|---|---|
| **Study Console** | Основний інструмент для практики. Шлях навчання, організований за 5 офіційними доменами іспиту (у порядку ваги згідно з blueprint), кожен з яких розбитий на свої **task statements**; шпаргалка з ключових принципів плюс таблиця рішень «IF trigger → THEN pattern»; режим Study у стилі флеш-карток (фільтрація за task statement або за наскрізним набором «Mixed / Applied», позначення питань як Known/Review, розкриття пояснень, перегляд автоматично визначених ключових слів у вигляді чипів); режим вікторини «Exam by Domain», у якому ви вмикаєте цілі домени або окремі task statements, обираєте кількість питань і отримуєте оцінений прогін з поясненням кожної помилки, а також однокліковий **повтор**, що прогонює заново лише питання, у яких ви помилилися, з миттєвим зворотним зв'язком по кожному питанню; а також вкладка **Concepts**, де перелічені всі 59 концепцій blueprint за доменом → task statement, кожна з ключовою ідеєю та рівнем Foundation/Intermediate/Advanced. |

## Вміст

- **156 практичних питань**, взятих з `CCA-F_Study_Guide.md`. Одна пара, чия правильна відповідь у джерелі справді суперечлива, позначена значком ⚠ у режимі Study.
- Застосунок організований навколо **офіційного blueprint CCA-F**: **5 доменів → 30 task statements → 59 концепцій**. Кожне питання прив'язане до одного task statement, з якого випливає його домен. П'ять доменів у порядку ваги на іспиті: Agentic Architecture (27%), Tool Design & MCP (18%), Claude Code & Workflows (20%), Prompt Engineering & Output (20%) та Context & Reliability (15%). (Таксономію blueprint взято з [prepgenaicerts.com/learn](https://www.prepgenaicerts.com/learn).)

## Можливості

- **Перемикач мови EN / NL / FR / DE / ID / IT / MS / PL / PT / ES / SV / VN / ZH / TW / JA / KO / HI / RU / UK / TH / EL / AR** — шар заміни тексту в реальному часі перекладає текст на екрані між англійською, нідерландською, французькою, німецькою, індонезійською, італійською, малайською, польською, португальською, іспанською, шведською, в'єтнамською, спрощеною китайською, традиційною китайською, японською, корейською, гінді, російською, українською, тайською, грецькою та арабською без перезавантаження сторінки; обрана мова зберігається при наступних відвідуваннях.
- **Теми Light / Dark / System / Sepia** — оберіть фіксований світлий або темний вигляд, дотримуйтесь налаштування системи, або перемкніться на теплу бурштиново-кремову тему Sepia (вона теж автоматично підлаштовується під світлий/темний режим); вибір зберігається при наступних відвідуваннях.
- **Автоматично позначені ключові слова** — кожне питання звіряється зі списком з десятків поширених термінів іспиту (наприклад, «MCP resource», «stateless», «tool_choice») і показує збіги у вигляді чипів, щоб вирішальна фраза впадала в очі ще до прочитання пояснення.
- **Локальне збереження** — прогрес навчання (позначки Known/Review) і стан чек-листа плану зберігаються через `localStorage`, з резервним варіантом у пам'яті для поточної вкладки, якщо сховище заблоковане.
- **Нульові залежності** — чистий JS/CSS/SVG без фреймворків і збірки; єдині зовнішні виклики — до Google Fonts (Space Grotesk, Inter, JetBrains Mono).
- **Необов'язкова підтримка** — кнопка «☕ Buy me a coffee» (завжди видима у верхній панелі навігації, з нагадуванням після завершення пробного іспиту) відкриває вікно з QR-кодами для кількох способів оплати; повністю необов'язкова та автоматично приховується, якщо жодне зображення QR-коду не налаштоване.
