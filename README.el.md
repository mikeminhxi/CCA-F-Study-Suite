Μια αυτόνομη στατική εφαρμογή για μελέτη ενόψει της εξέτασης πιστοποίησης της Anthropic **Claude Certified Architect — Foundations (CCA-F)**. Χωρίς βήμα build, χωρίς server, χωρίς εξαρτήσεις προς εγκατάσταση — κατεβάστε τον φάκελο και ανοίξτε το `index.html` σε έναν browser.

## Άνοιγμα

Κάντε διπλό κλικ στο [index.html](index.html), ή σερβίρετέ το με οποιονδήποτε στατικό file server. Η πρόοδος αποθηκεύεται τοπικά στον browser (`localStorage`), ανά συσκευή/browser. Κρατήστε τα `style.css` και `content.js` δίπλα στο `index.html` — η εφαρμογή χρειάζεται και τα δύο· αν ανοίξετε μόνο το `index.html`, θα εμφανιστεί σφάλμα αντί να φορτώσει. Προσθέστε επίσης τον φάκελο `translations/` για οποιαδήποτε γλώσσα εκτός των Αγγλικών — αν λείπει, η εφαρμογή επιστρέφει σιωπηλά στα Αγγλικά.

## Τι περιλαμβάνει

Η σελίδα είναι ένα κέλυφος με καρτέλες που συγκεντρώνει τέσσερα εργαλεία. Σε οθόνες πλάτους desktop (900px και άνω), κλειδώνει σε διάταξη σταθερού ύψους με sticky επάνω navigation bar, ώστε κάθε εργαλείο να κάνει scroll ανεξάρτητα· κάτω από αυτό το πλάτος, επιστρέφει σε μία ενιαία σελίδα με συνεχές scroll.

| Καρτέλα | Σκοπός |
|---|---|
| **Study Console** | Το βασικό εργαλείο εξάσκησης. Μια διαδρομή μάθησης οργανωμένη κατά τους 5 επίσημους τομείς εξέτασης (με τη σειρά βαρύτητας του blueprint), ο καθένας χωρισμένος στις **task statements** του· ένα cheat sheet βασικών αρχών συν έναν πίνακα αποφάσεων «ΑΝ trigger → ΤΟΤΕ pattern»· μια λειτουργία Study τύπου flashcard (φιλτράρισμα κατά task statement ή το εγκάρσιο σύνολο «Mixed / Applied», σήμανση ερωτήσεων ως Γνωστές/Προς επανάληψη, αποκάλυψη επεξηγήσεων, προβολή αυτόματα επισημασμένων keyword chips)· μια λειτουργία Quiz «Exam by Domain» όπου ενεργοποιείτε ολόκληρους τομείς ή μεμονωμένες task statements, επιλέγετε αριθμό ερωτήσεων και λαμβάνετε μια βαθμολογημένη συνεδρία με επεξήγηση κάθε λάθους, συν ένα **retake** με ένα κλικ που επαναλαμβάνει μόνο τις ερωτήσεις που χάσατε με άμεση ανατροφοδότηση ανά ερώτηση· και μια καρτέλα **Concepts** που παραθέτει και τις 59 έννοιες του blueprint κατά τομέα → task statement, η καθεμία με τη βασική της ιδέα και επίπεδο Foundation/Intermediate/Advanced. |

## Περιεχόμενο

- **156 ερωτήσεις εξάσκησης**, προερχόμενες από το `CCA-F_Study_Guide.md`. Ένα ζευγάρι με μια πράγματι αντικρουόμενη σωστή απάντηση στην πηγή επισημαίνεται με ένα σήμα ⚠ στη λειτουργία Study.
- Η εφαρμογή είναι οργανωμένη γύρω από το **επίσημο blueprint του CCA-F**: **5 τομείς → 30 task statements → 59 έννοιες**. Κάθε ερώτηση επισημαίνεται σε μία task statement, και ο τομέας της προκύπτει από αυτήν την επισήμανση. Οι πέντε τομείς, με τη σειρά βαρύτητας της εξέτασης: Agentic Architecture (27%), Tool Design & MCP (18%), Claude Code & Workflows (20%), Prompt Engineering & Output (20%), και Context & Reliability (15%). (Ταξινομία blueprint από [prepgenaicerts.com/learn](https://www.prepgenaicerts.com/learn).)

## Λειτουργίες

- **Εναλλαγή γλώσσας EN / NL / FR / DE / ID / IT / MS / PL / PT / ES / SV / VN / ZH / TW / JA / KO / HI / RU / UK / TH / EL / AR** — ένα επίπεδο αντικατάστασης κειμένου σε πραγματικό χρόνο μεταφράζει το περιεχόμενο στην οθόνη μεταξύ Αγγλικών, Ολλανδικών, Γαλλικών, Γερμανικών, Ινδονησιακών, Ιταλικών, Μαλαισιανών, Πολωνικών, Πορτογαλικών, Ισπανικών, Σουηδικών, Βιετναμέζικων, Απλοποιημένων Κινεζικών, Παραδοσιακών Κινεζικών, Ιαπωνικών, Κορεατικών, Χίντι, Ρωσικών, Ουκρανικών, Ταϊλανδέζικων, Ελληνικών και Αραβικών χωρίς επαναφόρτωση· η επιλεγμένη γλώσσα διατηρείται στις επόμενες επισκέψεις.
- **Θέματα Light / Dark / System / Sepia** — επιλέξτε σταθερή ανοιχτόχρωμη ή σκουρόχρωμη εμφάνιση, ακολουθήστε τη ρύθμιση του λειτουργικού σας συστήματος, ή περάστε σε ένα ζεστό θέμα Sepia σε αποχρώσεις κεχριμπαριού και κρέμας (που επίσης προσαρμόζεται αυτόματα σε ανοιχτό/σκούρο)· η επιλογή διατηρείται στις επόμενες επισκέψεις.
- **Αυτόματα επισημασμένες λέξεις-κλειδιά** — κάθε ερώτηση ελέγχεται σε σχέση με μια λίστα δεκάδων συνηθισμένων όρων εξέτασης (π.χ. «MCP resource», «stateless», «tool_choice») και εμφανίζει τα ταιριάσματα ως chips, ώστε η αποκαλυπτική φράση να ξεχωρίζει πριν διαβάσετε την επεξήγηση.
- **Τοπική διατήρηση** — η πρόοδος μελέτης (σημάνσεις Γνωστό/Προς επανάληψη) και η κατάσταση του checklist του πλάνου αποθηκεύονται μέσω `localStorage`, με μια εναλλακτική στη μνήμη για την τρέχουσα καρτέλα αν η αποθήκευση είναι μπλοκαρισμένη.
- **Καμία εξάρτηση** — καθαρή JS/CSS/SVG χωρίς framework ή εργαλεία build· οι μόνες εξωτερικές κλήσεις είναι στα Google Fonts (Space Grotesk, Inter, JetBrains Mono).
- **Προαιρετική υποστήριξη** — ένα κουμπί «☕ Κεράστε με έναν καφέ» (πάντα ορατό στο επάνω navigation bar, συν μια υπενθύμιση μετά την ολοκλήρωση μιας δοκιμαστικής εξέτασης) ανοίγει ένα modal με κωδικούς QR για μερικές επιλογές πληρωμής· είναι εντελώς προαιρετικό και κρύβεται αυτόματα αν δεν έχουν ρυθμιστεί εικόνες QR.
