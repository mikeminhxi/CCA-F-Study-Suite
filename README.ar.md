🔗 **العرض التجريبي المباشر:** https://mikeminhxi.github.io/CCA-F-Study-Suite/

تطبيق ثابت مستقل للاستعداد لامتحان اعتماد Anthropic **Claude Certified Architect — Foundations (CCA-F)**. بدون خطوة بناء (build)، وبدون خادم، وبدون أي تبعيات يجب تثبيتها — نزّل المجلد وافتح `index.html` في متصفح.

## فتح التطبيق

انقر نقرًا مزدوجًا على [index.html](index.html)، أو قدّمه عبر أي خادم ملفات ثابت. يُحفظ التقدّم محليًا في المتصفح (`localStorage`)، لكل جهاز/متصفح على حدة. احتفظ بملفي `style.css` و`content.js` بجانب `index.html` — يحتاج التطبيق إلى كليهما؛ فتح `index.html` وحده سيُظهر خطأً بدلاً من التحميل. أضف أيضًا مجلد `translations/` لأي لغة غير الإنجليزية — بدونه، يعود التطبيق بصمت إلى الإنجليزية.

## محتويات الصفحة

الصفحة عبارة عن غلاف بعلامات تبويب يجمع أربع أدوات. على الشاشات بعرض سطح المكتب (900 بكسل فأكثر)، يثبّت التطبيق تخطيطًا بارتفاع ثابت مع شريط تنقل علوي لاصق، بحيث تُمرَّر كل أداة بشكل مستقل؛ وتحت هذا العرض، يعود التطبيق إلى صفحة واحدة تُمرَّر بشكل متواصل.

| علامة التبويب | الغرض |
|---|---|
| **Study Console** | أداة التدريب الرئيسية. مسار تعلّم منظّم حسب مجالات الامتحان الرسمية الخمسة (بترتيب الوزن في المخطط التفصيلي - blueprint)، وكل مجال مقسّم إلى **بيانات المهام** (task statements) الخاصة به؛ ورقة مرجعية (cheat sheet) للمبادئ الأساسية بالإضافة إلى جدول قرارات «إذا كان المحفّز ← فإن النمط»؛ وضع Study على طراز البطاقات التعليمية (تصفية حسب بيان المهمة أو مجموعة «Mixed / Applied» الشاملة، وتحديد الأسئلة كمعروفة/تحتاج مراجعة، وكشف الشروحات، ورؤية شرائح الكلمات المفتاحية الموسومة تلقائيًا)؛ وضع اختبار «Exam by Domain» حيث تُفعّل مجالات كاملة أو بيانات مهام فردية، وتختار عدد الأسئلة، وتحصل على جلسة مُقيَّمة مع شرح كل خطأ، بالإضافة إلى **إعادة محاولة** بنقرة واحدة تعيد التدريب فقط على الأسئلة التي أخطأت فيها مع ملاحظات فورية لكل سؤال؛ وعلامة تبويب **Concepts** التي تسرد جميع مفاهيم المخطط التفصيلي الـ59 حسب المجال ← بيان المهمة، كل منها مع فكرته الأساسية ومستوى Foundation/Intermediate/Advanced. |
| **Study Hub** | عرض مرجعي منظّم حسب مجالات الامتحان الرسمية الخمسة (موزونة D1–D5)، مع قواعد قرار لكل مجال، وفخاخ يجب تجنبها، ومحفزات كلمات مفتاحية، بالإضافة إلى جدول فك تشفير سريع قابل للبحث. |
| **Neuron Map** | خريطة مفاهيم تفاعلية بصيغة SVG تربط مجالات الامتحان بمواضيعها الفرعية، مع روابط «مشبكية» (synapse) عابرة للمجالات يمكنك استكشافها بالنقر. |
| **2-Week Plan** | خطة دراسة يومية على شكل قائمة تحقق (checklist) بشريط تقدّم خاص بها؛ تتضمن حلاً بديلاً يدويًا للتصدير/الاستيراد بصيغة JSON للحالات التي لا يتوفر فيها `localStorage` (مثل بعض إعدادات `file://`). |

## المحتوى

- **156 سؤال تدريبي**، مأخوذة من `CCA-F_Study_Guide.md`. زوج واحد له إجابة مصدر متضاربة فعليًا مُعلَّم بشارة ⚠ في وضع Study.
- التطبيق منظَّم حول **المخطط التفصيلي الرسمي لـCCA-F**: **5 مجالات ← 30 بيان مهمة ← 59 مفهومًا**. كل سؤال موسوم ببيان مهمة واحد، ومجاله ينبع من هذا الوسم. المجالات الخمسة، بترتيب وزن الامتحان: Agentic Architecture ‏(27%)، وTool Design & MCP ‏(18%)، وClaude Code & Workflows ‏(20%)، وPrompt Engineering & Output ‏(20%)، وContext & Reliability ‏(15%). (تصنيف المخطط التفصيلي من [prepgenaicerts.com/learn](https://www.prepgenaicerts.com/learn).)

## الميزات

- **تبديل اللغة EN / NL / FR / DE / ID / IT / MS / PL / PT / ES / SV / VN / ZH / TW / JA / KO / HI / RU / UK / TH / EL / AR / HE** — طبقة استبدال نص في وقت التشغيل تترجم المحتوى الظاهر على الشاشة بين الإنجليزية والهولندية والفرنسية والألمانية والإندونيسية والإيطالية والملايوية والبولندية والبرتغالية والإسبانية والسويدية والفيتنامية والصينية المبسطة والصينية التقليدية واليابانية والكورية والهندية والروسية والأوكرانية والتايلاندية واليونانية والعربية والعبرية دون إعادة تحميل الصفحة؛ تُحفظ اللغة المختارة عبر الزيارات اللاحقة.
- **سمات فاتح / داكن / النظام / Sepia** — اختر مظهرًا فاتحًا أو داكنًا ثابتًا، أو اتبع إعداد نظام التشغيل لديك، أو بدّل إلى سمة Sepia الدافئة بألوان الكهرمان والكريمي (تتكيف أيضًا تلقائيًا مع الفاتح/الداكن)؛ يُحفظ الاختيار عبر الزيارات اللاحقة.
- **كلمات مفتاحية موسومة تلقائيًا** — يُقارَن كل سؤال بقائمة من عشرات المصطلحات الشائعة في الامتحان (مثل «MCP resource» و«stateless» و«tool_choice») وتُعرض المطابقات كشرائح، بحيث تبرز العبارة الكاشفة قبل قراءة الشرح.
- **حفظ محلي** — يُحفظ تقدّم الدراسة (علامات معروف/مراجعة) وحالة قائمة تحقق الخطة عبر `localStorage`، مع حل بديل في الذاكرة للعلامة التبويب الحالية إذا كان التخزين محظورًا.
- **بلا أي تبعيات** — JS/CSS/SVG خام دون أي إطار عمل أو أدوات بناء؛ النداءات الخارجية الوحيدة هي إلى Google Fonts ‏(Space Grotesk وInter وJetBrains Mono).
- **دعم اختياري** — يفتح زر «☕ اشترِ لي قهوة» (ظاهر دائمًا في شريط التنقل العلوي، مع تنبيه إضافي بعد إنهاء امتحان تدريبي) نافذة منبثقة برمز QR مع بعض خيارات الدفع؛ وهو اختياري تمامًا ويُخفى تلقائيًا إذا لم تُهيَّأ أي صور QR.
