אפליקציה סטטית עצמאית ללימוד למבחן ההסמכה של Anthropic **Claude Certified Architect — Foundations (CCA-F)**. ללא שלב build, ללא שרת, וללא תלויות להתקנה — הורידו את התיקייה ופתחו את `index.html` בדפדפן.

## פתיחת האפליקציה

לחצו לחיצה כפולה על [index.html](index.html), או הגישו אותו דרך כל שרת קבצים סטטי. ההתקדמות נשמרת מקומית בדפדפן (`localStorage`), בנפרד לכל מכשיר/דפדפן. שמרו את הקבצים `style.css` ו-`content.js` לצד `index.html` — האפליקציה זקוקה לשניהם; פתיחת `index.html` לבדו תציג שגיאה במקום להיטען. הוסיפו גם את התיקייה `translations/` עבור כל שפה שאינה אנגלית — בלעדיה, האפליקציה חוזרת בשקט לאנגלית.

## מה יש בדף

הדף הוא מעטפת עם כרטיסיות המאגדת ארבעה כלים. במסכים ברוחב שולחן עבודה (900 פיקסלים ומעלה), האפליקציה ננעלת לפריסה בגובה קבוע עם סרגל ניווט עליון דביק, כך שכל כלי גולל בנפרד; מתחת לרוחב זה, האפליקציה חוזרת לדף יחיד שגולל ברצף.

| כרטיסייה | מטרה |
|---|---|
| **Study Console** | הכלי המרכזי לתרגול. מסלול למידה המאורגן לפי חמשת תחומי המבחן הרשמיים (בסדר משקל התוכנית - blueprint), כל אחד מפוצל ל**הצהרות משימה** (task statements) משלו; דף עזר (cheat sheet) של העקרונות המרכזיים בתוספת טבלת החלטות "אם הטריגר ← אז הדפוס"; מצב Study בסגנון כרטיסיות לימוד (סינון לפי הצהרת משימה או קבוצת "Mixed / Applied" חוצת-תחומים, סימון שאלות כ-Known/Review, חשיפת הסברים, צפייה בתגי מילות מפתח שתויגו אוטומטית); מצב מבחן "Exam by Domain" שבו מפעילים תחומים שלמים או הצהרות משימה בודדות, בוחרים מספר שאלות, ומקבלים הרצה מדורגת עם הסבר לכל טעות, בתוספת **חזרה** בלחיצה אחת שמתרגלת מחדש רק את השאלות שטעיתם בהן עם משוב מיידי לכל שאלה; וכרטיסיית **Concepts** המפרטת את כל 59 המושגים של התוכנית לפי תחום ← הצהרת משימה, כל אחד עם התובנה המרכזית שלו ורמת Foundation/Intermediate/Advanced. |
| **Study Hub** | תצוגת עזר המאורגנת לפי חמשת תחומי המבחן הרשמיים (משוקללים D1–D5), עם כללי החלטה לכל תחום, מלכודות להימנע מהן, וטריגרים של מילות מפתח, בתוספת טבלת פענוח מהיר הניתנת לחיפוש. |
| **Neuron Map** | מפת מושגים אינטראקטיבית בפורמט SVG המקשרת בין תחומי המבחן לתתי-הנושאים שלהם, עם קישורי "סינפסה" חוצי-תחומים שניתן לחקור בלחיצה. |
| **2-Week Plan** | תוכנית לימוד יומית בסגנון רשימת סימון (checklist) עם פס התקדמות משלה; כוללת גיבוי ידני לייצוא/ייבוא בפורמט JSON למקרים שבהם `localStorage` אינו זמין (למשל הגדרות `file://` מסוימות). |

## תוכן

- **156 שאלות תרגול**, מקורן ב-`CCA-F_Study_Guide.md`. זוג אחד עם תשובת מקור סותרת בפועל מסומן בתג ⚠ במצב Study.
- האפליקציה מאורגנת סביב **התוכנית הרשמית של CCA-F**: **5 תחומים ← 30 הצהרות משימה ← 59 מושגים**. כל שאלה מתויגת להצהרת משימה אחת, והתחום שלה נגזר מתיוג זה. חמשת התחומים, בסדר משקל המבחן: Agentic Architecture (27%), Tool Design & MCP (18%), Claude Code & Workflows (20%), Prompt Engineering & Output (20%), ו-Context & Reliability (15%). (טקסונומיית התוכנית מתוך [prepgenaicerts.com/learn](https://www.prepgenaicerts.com/learn).)

## תכונות

- **החלפת שפה EN / NL / FR / DE / ID / IT / MS / PL / PT / ES / SV / VN / ZH / TW / JA / KO / HI / RU / UK / TH / EL / AR / HE** — שכבת החלפת טקסט בזמן ריצה מתרגמת את התוכן המוצג על המסך בין אנגלית, הולנדית, צרפתית, גרמנית, אינדונזית, איטלקית, מלאית, פולנית, פורטוגזית, ספרדית, שוודית, וייטנאמית, סינית מפושטת, סינית מסורתית, יפנית, קוריאנית, הינדי, רוסית, אוקראינית, תאית, יוונית, ערבית ועברית ללא טעינה מחדש; השפה הנבחרת נשמרת בביקורים הבאים.
- **ערכות נושא בהיר / כהה / מערכת / Sepia** — בחרו מראה בהיר או כהה קבוע, עקבו אחר הגדרת מערכת ההפעלה שלכם, או עברו לערכת Sepia חמימה בגוני ענבר וקרם (מתאימה את עצמה אוטומטית גם לבהיר/כהה); הבחירה נשמרת בביקורים הבאים.
- **מילות מפתח מתויגות אוטומטית** — כל שאלה נבדקת מול רשימה של עשרות מונחים נפוצים במבחן (כגון "MCP resource", "stateless", "tool_choice") וההתאמות מוצגות כתגיות, כך שהביטוי המסגיר בולט לפני קריאת ההסבר.
- **שמירה מקומית** — התקדמות הלימוד (סימוני Known/Review) ומצב רשימת הסימון של התוכנית נשמרים דרך `localStorage`, עם גיבוי בזיכרון לכרטיסייה הנוכחית אם האחסון חסום.
- **ללא תלויות** — JS/CSS/SVG גולמיים ללא כל framework או כלי build; הקריאות החיצוניות היחידות הן ל-Google Fonts (Space Grotesk, Inter, JetBrains Mono).
- **תמיכה אופציונלית** — כפתור "☕ קנו לי קפה" (מוצג תמיד בסרגל הניווט העליון, עם קריאה נוספת לאחר סיום מבחן תרגול) פותח חלון קופץ עם קוד QR ומספר אפשרויות תשלום; אופציונלי לחלוטין ומוסתר אוטומטית אם לא הוגדרו תמונות QR.
