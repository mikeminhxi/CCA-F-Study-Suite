Автономный HTML-файл для подготовки к сертификационному экзамену Anthropic **Claude Certified Architect — Foundations (CCA-F)**. Никакой сборки, никакого сервера, никаких зависимостей для установки — просто откройте `index.html` в браузере.

## Открытие файла

Дважды щёлкните по [index.html](index.html) или обслуживайте его через любой статический файловый сервер. Прогресс сохраняется локально в браузере (`localStorage`), для каждого устройства/браузера отдельно.

## Содержимое страницы

Страница представляет собой оболочку с вкладками, объединяющую четыре инструмента. На широких экранах (от 900px) она фиксируется в макете с фиксированной высотой и закреплённой верхней панелью навигации, так что каждый инструмент прокручивается независимо; ниже этой ширины страница возвращается к единой непрерывно прокручиваемой странице.

| Вкладка | Назначение |
|---|---|
| **Study Console** | Основной инструмент для практики. Путь обучения, организованный по 5 официальным доменам экзамена (в порядке веса согласно blueprint), каждый из которых разбит на свои **task statements**; шпаргалка по ключевым принципам плюс таблица решений «ЕСЛИ триггер → ТО паттерн»; режим Study в стиле карточек (фильтрация по task statement или по сквозному набору «Mixed / Applied», отметка вопросов как «Известно»/«Повторить», раскрытие объяснений, просмотр автоматически определённых ключевых слов в виде чипов); режим викторины «Exam by Domain», в котором вы активируете целые домены или отдельные task statements, выбираете количество вопросов и получаете оценённую сессию с объяснением каждой ошибки, а также однокликовый **повтор**, который прогоняет заново только вопросы, в которых вы ошиблись, с мгновенной обратной связью по каждому вопросу; а также вкладка **Concepts**, где перечислены все 59 концепций blueprint по домену → task statement, каждая с ключевой идеей и уровнем Foundation/Intermediate/Advanced. |
| **Study Hub** | Справочный вид, организованный по 5 официальным доменам экзамена (взвешенным D1–D5), с правилами принятия решений по каждому домену, ловушками, которых следует избегать, и триггерными ключевыми словами, а также таблица быстрой расшифровки с возможностью поиска. |
| **Neuron Map** | Интерактивная SVG-карта концепций, связывающая домены экзамена с их подтемами, с междоменными «синаптическими» связями, которые можно исследовать кликом. |
| **2-Week Plan** | Двухнедельный план обучения в виде ежедневного чек-листа с собственной шкалой прогресса; включает ручной резервный вариант экспорта/импорта JSON для случаев, когда `localStorage` недоступен (например, некоторые конфигурации `file://`). |

## Учебные материалы

- **156 практических вопросов**, взятых из `CCA-F_Study_Guide.md`. Пара, чей правильный ответ в источнике действительно противоречив, отмечена значком ⚠ в режиме Study.
- Приложение организовано вокруг **официального blueprint CCA-F**: **5 доменов → 30 task statements → 59 концепций**. Каждый вопрос привязан к task statement, из которого следует его домен. Пять доменов в порядке веса на экзамене: Agentic Architecture (27%), Tool Design & MCP (18%), Claude Code & Workflows (20%), Prompt Engineering & Output (20%) и Context & Reliability (15%). (Таксономия blueprint взята с [prepgenaicerts.com/learn](https://www.prepgenaicerts.com/learn).)

## Возможности

- **Переключатель языка EN / FR / DE / IT / PT / ES / VN / 简体中文 / 繁體中文 / JA / 한국어 / HI / RU** — слой замены текста в реальном времени переводит отображаемый текст между английским, французским, немецким, итальянским, португальским, испанским, вьетнамским, упрощённым китайским, традиционным китайским, японским, корейским, хинди и русским без перезагрузки страницы; выбранный язык сохраняется при последующих посещениях.
- **Темы Светлая / Тёмная / Системная / Sepia** — выберите фиксированный светлый или тёмный вид, следуйте настройке системы, либо переключитесь на тёплую янтарно-кремовую тему Sepia (она тоже автоматически подстраивается под светлый/тёмный режим); выбор сохраняется при последующих посещениях.
- **Автоматически отмеченные ключевые слова** — каждый вопрос сверяется со списком из десятков распространённых терминов экзамена (например, «MCP resource», «stateless», «tool_choice») и показывает совпадения в виде чипов, чтобы решающая фраза бросалась в глаза ещё до чтения объяснения.
- **Локальное сохранение** — прогресс обучения (отметки «Известно»/«Повторить») и состояние чек-листа плана сохраняются через `localStorage`, с резервным вариантом в памяти для текущей вкладки, если хранилище заблокировано.
- **Нулевые зависимости** — чистый JS/CSS/SVG в одном файле; единственные внешние вызовы — к Google Fonts (Space Grotesk, Inter, JetBrains Mono).
- **Необязательная поддержка** — кнопка «☕ Угостить меня кофе» (всегда видна в верхней панели навигации, с напоминанием после завершения пробного экзамена) открывает окно с QR-кодами для нескольких способов оплаты; полностью необязательна и автоматически скрывается, если ни одно изображение QR-кода не настроено.
