แอปสแตติกแบบสแตนด์อโลนสำหรับเตรียมสอบ **Claude Certified Architect — Foundations (CCA-F)** ของ Anthropic ไม่ต้อง build ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องติดตั้ง dependency ใด ๆ — แค่เปิด `index.html` ในเบราว์เซอร์ก็ใช้งานได้

## เปิดใช้งาน

ดับเบิลคลิกที่ [index.html](index.html) หรือเสิร์ฟผ่าน static file server ใดก็ได้ ความคืบหน้าจะถูกบันทึกไว้ในเบราว์เซอร์ (`localStorage`) แยกตามอุปกรณ์/เบราว์เซอร์ เก็บ `style.css`, `content.js` และโฟลเดอร์ `translations/` ไว้ข้าง ๆ `index.html` เสมอ — แอปต้องใช้ไฟล์เหล่านี้ทั้งหมด หากเปิด `index.html` เพียงไฟล์เดียว จะขึ้นข้อความแสดงข้อผิดพลาดแทนที่จะโหลดแอปขึ้นมา

## มีอะไรอยู่ข้างใน

หน้าเว็บเป็นเชลล์แบบแท็บที่รวมเครื่องมือทั้ง 4 อย่างไว้ด้วยกัน บนหน้าจอความกว้างระดับเดสก์ท็อป (900px ขึ้นไป) จะล็อกเป็นเลย์เอาต์ความสูงคงที่พร้อมแถบนำทางด้านบนแบบ sticky ทำให้แต่ละเครื่องมือเลื่อนได้อย่างอิสระ; ต่ำกว่าความกว้างนี้จะกลับไปเป็นหน้าเดียวที่เลื่อนต่อเนื่อง

| แท็บ | จุดประสงค์ |
|---|---|
| **Study Console** | เครื่องมือฝึกฝนหลัก เส้นทางการเรียนรู้ที่จัดเรียงตาม 5 โดเมนข้อสอบอย่างเป็นทางการ (เรียงตามลำดับน้ำหนักใน blueprint) แต่ละโดเมนแบ่งย่อยเป็น **task statement** ของตัวเอง; cheat sheet สรุปหลักการสำคัญ พร้อมตารางการตัดสินใจแบบ "IF trigger → THEN pattern"; โหมด Study สไตล์ flashcard (กรองตาม task statement หรือชุดข้ามโดเมน "Mixed / Applied" ทำเครื่องหมายคำถามเป็น Known/Review เปิดดูคำอธิบาย ดู keyword ที่ติดแท็กอัตโนมัติในรูปแบบชิป); โหมด Quiz "Exam by Domain" ที่ให้คุณเปิด/ปิดทั้งโดเมนหรือ task statement แต่ละรายการ เลือกจำนวนคำถาม แล้วได้รอบทดสอบที่ให้คะแนนพร้อมคำอธิบายทุกข้อที่ตอบผิด บวกกับฟีเจอร์ **retake** แบบคลิกเดียวที่ทบทวนเฉพาะข้อที่ตอบผิดพร้อมฟีดแบ็กทันทีทีละข้อ; และแท็บ **Concepts** ที่แสดงรายการ concept ทั้ง 59 รายการใน blueprint ตามโดเมน → task statement แต่ละรายการมาพร้อม insight หลักและระดับ Foundation/Intermediate/Advanced |
| **Study Hub** | มุมมองอ้างอิงที่จัดเรียงตาม 5 โดเมนข้อสอบอย่างเป็นทางการ (ถ่วงน้ำหนัก D1–D5) พร้อมกฎการตัดสินใจรายโดเมน กับดักที่ควรหลีกเลี่ยง และคำสำคัญกระตุ้นความจำ รวมถึงตารางถอดรหัสด่วนที่ค้นหาได้ |
| **Neuron Map** | แผนที่ concept แบบ SVG เชิงโต้ตอบที่เชื่อมโยงโดเมนข้อสอบกับหัวข้อย่อยของมัน พร้อมเส้นเชื่อม "synapse" ข้ามโดเมนที่คลิกไล่ดูได้ |
| **2-Week Plan** | แผนการเรียนแบบเช็กลิสต์รายวัน มีแถบความคืบหน้าของตัวเอง; มีระบบสำรองสำหรับ export/import JSON แบบแมนวล สำหรับกรณีที่ `localStorage` ใช้งานไม่ได้ (เช่น การเปิดผ่าน `file://` บางรูปแบบ) |

## เนื้อหา

- **คำถามฝึกฝน 156 ข้อ** นำมาจาก `CCA-F_Study_Guide.md` มีคู่คำถามหนึ่งคู่ที่คำตอบในต้นฉบับขัดแย้งกันจริง ๆ ซึ่งจะถูกทำเครื่องหมายด้วยแบดจ์ ⚠ ในโหมด Study
- แอปนี้จัดโครงสร้างตาม **blueprint อย่างเป็นทางการของ CCA-F**: **5 โดเมน → 30 task statement → 59 concept** ทุกคำถามจะถูกแท็กไปยัง task statement เดียว และโดเมนของมันก็มาจากแท็กนั้น ห้าโดเมนเรียงตามลำดับน้ำหนักข้อสอบ ได้แก่ Agentic Architecture (27%), Tool Design & MCP (18%), Claude Code & Workflows (20%), Prompt Engineering & Output (20%) และ Context & Reliability (15%) (อนุกรมวิธานของ blueprint จาก [prepgenaicerts.com/learn](https://www.prepgenaicerts.com/learn))

## ฟีเจอร์

- **ตัวสลับภาษา EN / FR / DE / ID / IT / MS / PL / PT / ES / VN / 简体中文 / 繁體中文 / JA / 한국어 / HI / RU / TH** — เลเยอร์แทนที่ข้อความแบบเรียลไทม์ที่แปลเนื้อหาบนหน้าจอระหว่างภาษาอังกฤษ ฝรั่งเศส เยอรมัน อินโดนีเซีย อิตาลี มลายู โปแลนด์ โปรตุเกส สเปน เวียดนาม จีนตัวย่อ จีนตัวเต็ม ญี่ปุ่น เกาหลี ฮินดี รัสเซีย และไทย โดยไม่ต้องโหลดหน้าใหม่; ภาษาที่เลือกไว้จะถูกจดจำในการเข้าชมครั้งถัดไป
- **ธีม Light / Dark / System / Sepia** — เลือกโทนสว่างหรือมืดแบบตายตัว ใช้ตามการตั้งค่าของระบบปฏิบัติการ หรือเปลี่ยนไปใช้ธีม Sepia โทนอำพัน-ครีมที่อบอุ่น (ซึ่งก็ปรับตามสว่าง/มืดโดยอัตโนมัติเช่นกัน); ตัวเลือกจะถูกจดจำในการเข้าชมครั้งถัดไป
- **คำสำคัญที่ติดแท็กอัตโนมัติ** — แต่ละคำถามจะถูกตรวจสอบกับรายการคำศัพท์เฉพาะของข้อสอบหลายสิบคำ (เช่น "MCP resource", "stateless", "tool_choice") และแสดงคำที่ตรงกันเป็นชิป เพื่อให้วลีที่เป็นตัวชี้เบาะแสโดดเด่นขึ้นมาก่อนที่คุณจะอ่านคำอธิบาย
- **การบันทึกข้อมูลในเครื่อง** — ความคืบหน้าการเรียน (เครื่องหมาย known/review) และสถานะเช็กลิสต์ของแผนจะถูกบันทึกผ่าน `localStorage` พร้อมระบบสำรองแบบเก็บในหน่วยความจำสำหรับแท็บปัจจุบัน หากระบบจัดเก็บถูกบล็อก
- **ไม่มี dependency** — JS/CSS/SVG แบบ vanilla ล้วน ๆ ไม่มี framework หรือเครื่องมือ build; การเรียกข้อมูลจากภายนอกมีเพียง Google Fonts (Space Grotesk, Inter, JetBrains Mono) เท่านั้น
- **การสนับสนุนแบบไม่บังคับ** — ปุ่ม "☕ Buy me a coffee" (แสดงอยู่ในแถบนำทางด้านบนเสมอ พร้อมข้อความชวนหลังทำข้อสอบจำลองเสร็จ) จะเปิดหน้าต่างโค้ด QR สำหรับช่องทางชำระเงินไม่กี่แบบ; เป็นฟีเจอร์ที่ไม่บังคับโดยสิ้นเชิงและจะซ่อนอัตโนมัติหากไม่มีการตั้งค่ารูปภาพ QR ไว้
